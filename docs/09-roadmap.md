## M0 怎么看效果

1. `npm install`，然后 `npm run tauri dev`（开发）或 `npm run tauri build`（安装包在 `src-tauri/target/release/bundle/nsis/`）。
2. 启动后宠物出现在主屏右下方，托盘出现图标。没有 `instances.json` 时用内置的「团子」。
3. **拖拽**：按住宠物拖动，有晃动和落地挤压；松手后位置会记住，重启还在。
4. **穿透**：宠物透明处和其他地方的点击都落到下面的程序；点宠物不会抢走键盘焦点。
5. **找回宠物**：托盘「找回宠物」或热键（`Ctrl+Alt+P`，被占用时依次换 `I`、`U`，托盘里显示实际的键）——宠物显示虚线框、整个框都可点，跑出屏幕的会被拉回来；20 秒后自动关闭。再次启动程序也会闪一下虚线框。
6. **插件**：把 `examples/plugins/state-tester` 复制到 `%APPDATA%/com.petween.app/plugins/`，重启；托盘出现「状态测试：下一个」，每点一次换一个状态。
7. **热重载**：托盘勾上「插件开发模式」，再改插件文件，保存即生效。
8. **v0 宠物**：`node tools/convert-v0.mjs --main`（先退出 Petween）。
9. 日志：`%APPDATA%/com.petween.app/petween.log`。
