## M0 怎么看效果

1. `npm install`，然后 `npm run tauri dev`（开发）或 `npm run tauri build`（安装包在 `src-tauri/target/release/bundle/nsis/`）。
2. 启动后宠物出现在主屏右下方，托盘出现图标。没有 `instances.json` 时用内置的「团子」。
3. **拖拽**：按住宠物拖动，有晃动和落地挤压；松手后位置会记住，重启还在。
4. **穿透**：宠物透明处和其他地方的点击都落到下面的程序；点宠物不会抢走键盘焦点。
5. **找回宠物**：托盘「找回宠物」或热键（`Ctrl+Alt+P`，被占用时依次换 `I`、`U`，托盘里显示实际的键）——宠物显示虚线框、整个框都可点，跑出屏幕的会被拉回来；20 秒后自动关闭。再次启动程序也会闪一下虚线框。
6. **插件**：把 `examples/plugins/state-tester` 复制到 `%APPDATA%/com.petween.app/plugins/`，重启；托盘出现「状态测试：下一个」，每点一次换一个状态。
7. **热重载**：托盘勾上「插件开发模式」，再改插件文件，保存即生效。
8. **v0 宠物**：`node tools/convert-v0.mjs --main`（先退出 Petween）。
9. 日志：`%APPDATA%/com.petween.app/petween.log`。

## M1 怎么看效果

1. 托盘「设置…」（或运行 `petween.exe --settings`）打开设置窗口：宠物 / 接入 / 插件 / 检查器 / 关于。
2. **接入**：在「接入」页点对应 agent 的「接入」。Claude Code 立即生效；Codex 下次启动会话时要确认一次信任；zcode 需要重启。用了 `CLAUDE_CONFIG_DIR` 的话，先在「插件 → Claude Code 接入 → 设置」里把那个目录加上，再接入。
3. 用 agent 干活：宠物随思考 / 改文件 / 跑命令 / 等你确认 / 成功 / 出错换表情；旁边有实时统计小条；回合结束冒出回复摘要和本轮统计气泡。
4. **抛掷**：拖住宠物快速甩出去松手，会飞、落下、撞墙弹、贴地滑行后停下。
5. **多宠物**：「宠物」页「再养一只」；或在「接入」页把会话绑定改成「每个会话一只宠物」。
6. **检查器**：实时看每个通道是谁在控制。

## DSH 接入（2026-10-24 补充）

`dsh` connector 不走 `petween.exe --hook`：DSH 没有 hook 命令，接入时会在 `$DSH_HOME` 写一个桥接插件，并在 `$DSH_HOME/cordis.patch.yml` 追加一段。原理和边界见 [05 §1.2](05-agent-signals.md)。

1. 设置 →「接入」→「DeepSeek Harness (DSH)」→「接入」。
2. 完全退出并重开 DSH（桌面端连托盘一起退出）。补丁在启动时组合，只开设置页不会生效。
3. 在 DSH 里跑一个会话：宠物应随思考 / 改文件 / 跑命令 / 等你批准 / 成功 / 出错变表情；断开后不再变化。子会话不会单独生成宠物。
4. 用了自定义 `DSH_HOME` 的话，先在「插件 → DSH 接入 → 设置」里把「DSH 数据目录」改成那个目录，再接入。

## M2 怎么看效果

1. **粒子**：宠物进入「成功」时撒花（agent 回合成功，或用下面的状态测试器点 `success`）。设置 → 插件 → 粒子 → 设置：改成功 / 出错时放什么、数量。
2. **插件自带设置页**：把 `examples/plugins/state-tester` 复制到 `%APPDATA%/com.petween.app/plugins/`，重启；设置 → 插件 → 状态测试器 → 设置，出现它自己画的页面：每个状态一个按钮，点了主宠物立刻切过去；「自动交还」改了立即生效。改 `settings.js` 后收起再展开就能看到新版。

## M3a 怎么看效果

1. **打开**：托盘「宠物编辑器…」、设置 →「宠物」→「宠物编辑器」或某个宠物包的「编辑」、或 `petween.exe --editor`。
2. **状态树**（左上）：所有可能出现的状态；实心点 = 这个宠物包单独设置了，空心 = 回退，右边写着回退到哪。底部可以加任意状态键（如 `active.command.Bash`）。
3. **导入**（左下）：把图片 / GIF / 短视频拖进片段库，或点「导入素材」；AI 图片背景不透明时勾「导入时去掉纯色背景」。
4. **配状态**（右侧）：选状态 →「单独设置这个状态」→ 加画面、选进入 / 持续 / 离开动作、切换方式。中间预览实时变；「▶ 重播切换」看切换效果，下拉框选「从 X 切过来」。
5. **对齐**：选片段 →「在预览里拖动对齐」，拖动图片让脚底落在红十字上，半透明的是参照图；「大小」滑块调尺寸。
6. **在桌面上试**：顶部按钮，桌面上的宠物立刻穿上当前草稿并跟着你选的状态变；关掉编辑器或再点一次就恢复。
7. **保存**：Ctrl+S 或「保存」；桌面上穿这个包的宠物立即换新。内置的「团子」只读，「复制一份」再改。
8. **分享**：「导出」生成 `.petpack` 放到「下载」；「导入 .petpack」安装别人的。
9. **交给 agent**：设置 →「关于」→「复制给 agent」，粘贴给 Claude Code 等；它会读 `petween --pack guide`，用你的生图工具做素材并导入（docs/10）。

## M3b 怎么看效果

1. 打开宠物编辑器，左下切到「动作」页：上面是这个宠物包的动作（右边写着用在几处），中间是「我的动作库」，下面是内置预设。
2. **看**：点任意动作，中间预览在上一个选过的状态的画面上反复播它（一次性的播完停一下再播，持续的一直播）。
3. **改参数**：呼吸 / 摇摆 / 随机晃 / 弹簧这类动作，右侧是参数表单，改完预览立刻变。
4. **K 帧**：「蹦一下」这类动作，右侧是轨道条。双击轨道加关键帧，左右拖改时间，点中后在下面改数值和「过渡」；「＋ 加一条轨道」加别的属性；「时长」等比拉伸，「减弱 / 增强」整体缩放幅度；「播放方式」可改成「隔一阵播一次」当持续动作用。
5. **标记**：双击「标记」行加标记，选「换图」决定新画面在哪一刻换上，或选「放粒子：撒花」等。到桌面上验证：给 `success` 的进入动作加一个粒子标记，保存，用状态测试器切到 `success`。
6. **动作库**：在本包动作上点「存到我的动作库」；切换到另一个宠物包，在「我的动作库」里点它 →「加到这个宠物包」。库文件在 `%APPDATA%/com.petween.app/motion-library.json`。
7. **从状态跳过去**：状态面板「动作」下方「调形状：xxx →」直接跳到那个动作。
